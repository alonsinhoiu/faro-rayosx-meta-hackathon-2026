---

## 1. Architectural & Hardware Boundaries
- **Runtime Environment:** Node.js `v24.14.0` running natively on macOS (Apple A18 Pro, 8 GB Unified Memory).
- **Zero Local Model Weights:** Do NOT attempt to run local Llama/Muse Glimmer/GGUF weights. Memory limit is 8 GB. Ingest models strictly via Meta Cloud API (`https://api.meta.ai/v1`).
- **Persistence:** Use native `node:sqlite` (`import { DatabaseSync } from 'node:sqlite'`). Do NOT install heavyweight ORMs, Docker containers, or external database engines.
- **Client Bundle:** React 19 + TypeScript + Tailwind CSS. Fast, zero-lag rendering. Total dev RAM footprint must stay `< 250 MB`.

---

## 2. Deterministic Financial & Logical Constraints (No LLM Math)
- **Rule 1 (The LLM Never Calculates):**
  - Models (`muse-spark-1.3`) only EXTRACT raw numbers with direct textual citations (`listed_base_rent_clp`, `listed_ggcc_clp`, `broker_commission_pct`, `security_deposit_months`, `readjustment_mechanism`).
  - All financial formulas (`calculateTrueMonthlyCost`, `calculateYearOneTotal`, `amortizeBrokerFee`) MUST be pure deterministic TypeScript functions covered by unit tests.
- **Rule 2 (Hard Deal-Breaker Veto Gate):**
  - If `TrueMonthlyCost > User.max_total_budget_clp`, the property is IMMEDIATELY marked `VETOED_BY_BUDGET`.
  - If a user deal-breaker (e.g. `requires_pets = true`) has `status === 'fail'` in the contract or listing rubric, the property is marked `VETOED_BY_CONSTRAINT`.
  - Soft reasoning or aesthetic scores can NEVER override a hard boolean veto.
- **Rule 3 (Zero Guessed Values in Rubric):**
  - If an ad or contract omits a piece of data (e.g. HOA fee, pet policy, floor level, parking), the check MUST be assigned `status = 'unknown'`.
  - It is strictly forbidden to guess or treat an omitted field as `pass`.
  - The UI MUST compute and display `EvidenceCoveragePercent = (verified_checks / total_applicable_checks) * 100`.

## 3. Epistemic Provenance Rules (`Graphify-Labs/graphify`)
Every node and finding in the property analysis must carry one of the following provenance tags:
1. `[EXTRACTED_TEXT]` — Directly quoted from the listing ad with substring verification.
2. `[EXTRACTED_PHOTO]` — Detected by `muse-spark-1.3` with normalized `bbox_1000: { x_min, y_min, x_max, y_max }` coordinates.
3. `[EXTRACTED_PDF]` — Extracted from the draft lease PDF with page and clause reference.
4. `[EXTRACTED_VOICE]` — Transcribed from renter voice notes via `muse-voice-transcribe-1.0`.
5. `[INFERRED]` — Hypothesis generated by reasoning; MUST include explicit confidence rating and falsification condition.
6. `[CONTRADICTION]` — Direct logical conflict between two extracted sources (e.g. Ad says "Pet Friendly" vs. PDF Lease Clause 11 prohibits pets).

## 4. UI/UX Rules (`plugin87/ux-ui-agent-skills` / XIAS & Swiss-Editorial)
- **Eliminate AI Slop:**
  - ZERO `<Sparkles>` icons.
  - ZERO purple/indigo/aqua gradients (`from-indigo-500 to-emerald-400`).
  - ZERO fake phone frames (`PhoneFrame.jsx` with 9:41 status bars). Use full-width responsive desktop workbench.
- **WCAG 2.2 AA/AAA Contrast Standards:**
  - Base background: `#FAF8F5` (warm paper) or `#FFFFFF`.
  - Base typography: `#111827` (slate 900, 16.8:1 contrast).
  - Semantic Pass: `#047857` (emerald 700, 5.48:1 on white).
  - Semantic Warning / Unknown: `#B45309` (amber 700, 5.02:1 on white).
  - Semantic Fail / Contradiction: `#B91C1C` (red 700, 6.40:1 on white).
- **Typography & Numbers:**
  - All prices, scores, areas, coordinates, and dates MUST use `font-variant-numeric: tabular-nums` (Tailwind `tabular-nums`).
- **Interactive States:**
  - All interactive buttons and inputs must explicitly implement 8 states: `default`, `hover`, `active`, `focus-visible`, `disabled`, `loading`, `error`, `empty`.

## 5. Security & Spend Guardrails
- **Hard Spend Cap:** The backend SQLite ledger (`BudgetGuard`) must track API token and audio minute expenditures and reject outgoing calls if dev spend reaches `US$10.00`.
- **Untrusted Listing Shield:** User-pasted listing text must be treated as untrusted data. Sanitize and isolate from prompt instructions to block prompt injection attempts.
- **Never Commit Secrets:** `.env` is git-ignored. API keys are passed strictly through environment variables.
